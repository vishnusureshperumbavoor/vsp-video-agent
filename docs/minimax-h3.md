# MiniMax-H3: video with native audio on JarvisLabs

MiniMax H3 is an open-weights omni-modal model: one transformer denoises the
video and a 32 kHz stereo soundtrack in the same pass. There is no separate TTS
or foley step. Duration is 4–15 s at 24 fps.

- Weights: `MiniMaxAI/MiniMax-H3` (MiniMax H3 Community License, **not** Apache)
- ComfyUI repack: `Comfy-Org/MiniMax-H3`
- Runner: `scripts/h3_video.py`
- Graph builder: `scripts/minimax_h3/workflow.py` (pure, tested)
- Remote worker: `scripts/minimax_h3/worker.py`

## Why the quantized repack

| Build | Transformer | Text encoder | Fits 40 GB A100? |
| :--- | ---: | ---: | :--- |
| Official bf16 | 61.7 GB | 62.1 GB | No |
| Comfy pruned int8 + nvfp4 | 21 GB | 15.7 GB | Yes |

Total download is ~42 GB. The `nvfp4` text encoder does **not** require a
Blackwell card; the `int8_convrot` transformer requires PyTorch built with
**CUDA 13** (`2.11.0+cu130` on the `pytorch` template is fine).

## Quick start

```bash
# 1. plan only, no SSH
.venv/bin/python scripts/h3_video.py "a saxophonist in the rain" --dry-run

# 2. first run on a fresh instance (installs ComfyUI, pulls 42 GB)
.venv/bin/python scripts/h3_video.py "a saxophonist in the rain" \
  --machine-id 574386 --setup --yes

# 3. later runs reuse the warm server, then stop billing
.venv/bin/python scripts/h3_video.py "a saxophonist in the rain" \
  --machine-id 574386 --pause
```

Output goes to `public/videos/` (git-ignored). Size presets that keep the
32-pixel grid: `608x352`, `736x416` (fast), `960x544` (~2.3× slower than
`1344x768`, but still practical).

## Measured

| Setting | Result |
| :--- | :--- |
| 736×416, 124 frames (5.2 s), 8 steps | **44 s** total, 2.68 s/step |
| Model load on first request | ~20 s (20 GB staged) |
| Audio | AAC stereo, 32 kHz |
| File | ~1.3 MB for 5.2 s |

`snap_length(seconds)` rounds up to the model's `17k+5` frame grid, so a 5 s
request becomes 124 frames (5.17 s).

## How it runs

1. The CLI builds a ComfyUI API graph: `UNETLoader` → turbo LoRA → `CLIPLoader`
   (`type: minimax`) → `MiniMaxH3ImageToVideo` → `BasicGuider` +
   `res_multistep`/`simple` → `SamplerCustomAdvanced` → `VAEDecode` **and**
   `VAEDecodeAudio` → `CreateVideo` → `SaveVideo`.
2. The graph and `worker.py` are uploaded to `/home/app`.
3. The worker is spawned detached, submits to `127.0.0.1:8188`, polls
   `/history`, and prints `=== FILE <path>` lines.
4. The CLI reads each file back as base64 over SSH and optionally pauses the
   instance.

Job files and results deliberately avoid `scp`: the vendored `sync_up` /
`sync_down` run `scp` without `BatchMode` or `-n`, so a key that wants a
passphrase blocks forever instead of failing. `client.exec` uses `ssh -n` and is
safe, so everything travels over that channel.

## Gotchas that cost time

1. **`hf_hub_download` with `local_dir=models/<folder>` nests the repo path.**
   Files land at `models/vae/vae/x.safetensors` and ComfyUI lists them as
   `vae/x.safetensors`. Always pass `local_dir=models` and let the repo-relative
   filename create the folder. The CLI does this already.
2. **ComfyUI caches folder listings.** After adding weights, restart it
   (kill by port, then start; never `pkill -f` in the same compound command).
3. **Do not use the UI workflow JSON directly.** The official template uses a
   subgraph node, which `/prompt` cannot consume. The builder emits a flat
   API-format graph instead.
4. **Audio is easy to fake and hard to notice.** Verify, don't assume:

   ```bash
   ffprobe -v error -show_entries stream=codec_type,codec_name,channels,sample_rate \
     -of default=noprint_wrappers=1 out.mp4
   ffmpeg -hide_banner -i out.mp4 -af volumedetect -f null /dev/null 2>&1 \
     | grep -E "mean_volume|max_volume"
   ```

   A silent track still probes as AAC; `mean_volume` near `-91 dB` means empty.
5. **Only 768p-class is open.** `H3-Regenerate-2K` and `H3-Context-IR` are
   hosted-only pieces. Local runs cannot reach 2K or the reference orchestrator.
6. **License.** The MiniMax H3 Community License is not OSI-open. Read it
   before shipping anything generated by it.
7. **The API instance list lags behind a resume.** After `jl resume`, the new
   machine ID can be missing from `list_instances()` for a while, and the list
   may still show old IDs as "Running". Pass `--host` with the address from the
   `jl resume` output; the CLI registers it directly.
